A newspaper front page for Wednesday 18 November 2026: masthead date, headline
"SUMMIT DAY IN SHENZHEN", photo of a Shenzhen conference hall with US, China and
Russia flags, a cyclone spiral and a stricken tanker, plus headlines
"IRAN HITS US RADAR IN BAHRAIN", "CRIMEA BRIDGE STRUCK AGAIN", and
"CYCLONE AKVAN BEARS DOWN ON INDIA".

## Run it

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` (1024x1024 JPEG bytes, 175,656 bytes) to
`/output/entry.png`. Standard library only, no network, deterministic — two
runs produce identical bytes.
